# StudyCraft · English 3

เว็บทบทวน English 3 Units 3–4 รองรับคอมพิวเตอร์ iPad และโทรศัพท์

- สรุปศัพท์ 91 รายการ พร้อมคำอ่านไทยและเสียงอ่านภาษาอังกฤษ
- เกม Word Quest: Easy 4 คู่ / Medium 6 คู่ / Hard 8 คู่ เลือกหมวดศัพท์ได้
- สรุปไวยากรณ์ บทอ่าน และ Final Review
- แบบฝึก 104 ข้อ รวมชุดจำลอง 80 ข้อ พร้อมเหตุผลและคำแปลโจทย์เมื่อตอบผิด
- ความคืบหน้า ชุดเกมค้าง และสถิติ เก็บในเบราว์เซอร์ของผู้เล่นแต่ละคน

## เปิดเล่น

GitHub Pages: https://natnon-ux.github.io/english3-studycraft/

หรือดาวน์โหลดโค้ดแล้วเปิด index.html ในเบราว์เซอร์ ไม่ต้องติดตั้งแพ็กเกจ

แตะปุ่มลำโพงเพื่อเริ่มเสียง ระดับเสียงขึ้นอยู่กับเสียงสื่อของอุปกรณ์
คำอ่านไทยเป็นเสียงโดยประมาณ ใช้ฟังภาษาอังกฤษประกอบ

## เนื้อหา

สรุปและแบบฝึกเขียนใหม่เพื่อทบทวน ไม่ใช่ข้อสอบจริง ไม่รวม PDF ต้นฉบับ
ภาพตัวละคร ธีมบล็อก เพลง และเอฟเฟกต์เขียนใหม่ด้วย SVG/CSS/Web Audio
เสียงอ่านสร้างด้วย Microsoft Zira Desktop (en-US) และฝังไว้ใน voices.js

## โฮสต์

เว็บเป็น static HTML/CSS/JavaScript ใช้ GitHub Pages จาก main / (root)
ไม่ต้องใช้บัญชีลงชื่อเข้าเว็บไซต์ ไม่มี API key และไม่มีบริการภายนอกสำหรับเสียงอ่าน
