# StudyCraft · English 3

เว็บทบทวน English 3 Units 3–4 สำหรับคอมพิวเตอร์ iPad และโทรศัพท์

## เปิดใช้งาน

[เปิดโหมดจำศัพท์](https://natnon-ux.github.io/english3-studycraft/#cards) · [หน้าภาพรวม](https://natnon-ux.github.io/english3-studycraft/)

## สิ่งที่มีในเว็บ

- ศัพท์และสำนวน 168 รายการ พร้อมคำแปล ตัวอย่าง และเสียงอังกฤษกับเสียงอ่านคำแปลไทย
- Memory Deck: พลิกบัตร จำได้/ยังไม่แม่น เลือกคำแปล พิมพ์ศัพท์ ฟังแล้วเลือก และฟังสลับอังกฤษ–ไทย
- เลือกหมวด คำที่บันทึก หรือคำที่ยังไม่แม่น และฝึกเป็นชุด 10/20/ทั้งหมดได้
- Word Quest: เกมจับคู่ Easy / Medium / Hard
- ทวนจุดอ่อนจากข้อสอบที่ผิดหรือเว้น และศัพท์ที่พลาด พร้อมนัดทวนวันถัดไป
- แบบฝึก 104 ข้อ รวมข้อสอบจำลอง 80 ข้อ พร้อมแปลโจทย์ แปลทุกตัวเลือก และเหตุผลคำตอบ
- Reading มีหลักฐานไฮไลต์และคำแปล 28 ข้อ โดยเปิดเฉลยหลังตอบหรือหลังส่งข้อสอบจำลอง
- สรุปไวยากรณ์ บทอ่าน และ Final Review

เสียงไทยคือเสียงอ่าน **คำแปล** เช่น outstanding → โดดเด่น ยอดเยี่ยม
เสียงเริ่มเมื่อกดฟังเท่านั้น ปรับความเร็วและหยุดได้ เสียงเกมกับเสียงอ่านควบคุมแยกกัน

## ข้อมูลการฝึก

ความคืบหน้าและรอบที่ค้างบันทึกในเบราว์เซอร์ของแต่ละคน ไม่ต้องสมัครบัญชี
อุปกรณ์หรือเบราว์เซอร์ต่างกันมีประวัติแยกกัน การล้างข้อมูลเว็บจะลบประวัติในเครื่องนั้น

## เนื้อหาและเทคนิค

สรุปและแบบฝึกเรียบเรียงใหม่เพื่อทบทวน ไม่ใช่ข้อสอบจริง ไม่มีไฟล์ PDF ต้นฉบับแนบอยู่ใน repository
ธีมบล็อก ตัวละคร SVG/CSS และเสียงเกม Web Audio เขียนขึ้นสำหรับเว็บนี้
เสียงอังกฤษใช้ Microsoft Zira Desktop และเสียงคำแปลไทยใช้ th-TH-PremwadeeNeural ฝังข้อมูลเสียงไว้ในไฟล์ JavaScript

เว็บเป็น static HTML/CSS/JavaScript ใช้ GitHub Pages จาก main / (root)
ไม่มี API key และไม่ต้องเรียกบริการเสียงภายนอกระหว่างเรียน
ดาวน์โหลดไฟล์แล้วเปิด index.html ได้โดยไม่ต้องติดตั้งแพ็กเกจ
